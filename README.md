# ストーリーズメーカー

## 公開手順（GitHub Pages）
1. このフォルダの中身をGitHubリポジトリの `main` ブランチにアップロード
2. リポジトリの Settings → Pages → Source を **GitHub Actions** にする
3. 数分後に公開URLが発行されます（以降は push するたび自動更新）

## スタンプを追加する
`stamps/カテゴリー名/画像ファイル` の形で画像（png / svg / webp / jpg）を置くだけ。
フォルダ名がタブ名になります。並び順は `01_ドリンク` のように先頭に数字を付けると指定できます（表示では数字は消えます）。

## テンプレートを追加する
`templates/カテゴリー名/〇〇.json` を置くだけ。キャンバスは 1080×1920。座標は各要素の**中心位置**です。
```json
{
  "name": "テンプレート名",
  "background": "#FEF4E8",
  "photo": {"x": 90, "y": 200, "w": 900, "h": 1100},
  "objects": [
    {"type": "text", "text": "文字", "x": 540, "y": 1450, "font": "serif", "fontSize": 96, "fill": "#5D321A"},
    {"type": "stamp", "src": "stamps/03_デコ/heart.svg", "x": 900, "y": 230, "w": 220, "angle": 15}
  ]
}
```
- `font`: `sans`（ゴシック）/ `serif`（明朝）　`photo` を省略すると写真は全面表示
- JSONに誤りがあると、そのテンプレートだけ表示されません（Actionsのログに表示）

## フレーム画像でテンプレートを作る
1. **1080×1920px（縦長9:16）のPNG**で作ります。
2. 写真を入れたい部分を**透明**にして書き出します（白で塗りつぶさない）。穴は1つで、形は自由です（角を丸く切り欠く等もOK）。
   - Illustrator：白い図形を削除し、書き出しで背景を「透明」にする
   - Photopea（無料・ブラウザ）：自動選択ツールで白い部分を選択 → Delete → PNGで書き出し
3. 写真より手前に出したい装飾（キャラクター、リボン、文字）はフレーム画像に含めてOKです。
4. `templates/カテゴリー名/名前.png` に置くだけで登録されます。写真は穴の外接四角に合わせて自動配置され、フレームの下に入ります（ドラッグで位置、角のハンドルで拡大縮小）。
5. 初期配置の文字・スタンプも付けたい場合は、**同じ名前**の `名前.json` を同じフォルダに置きます（画像は自動で使われます）。
```json
{"name": "Today's Cake",
 "objects": [{"type": "text", "text": "ガトーショコラ", "x": 540, "y": 1500, "font": "serif", "fontSize": 90, "fill": "#5D321A"}]}
```
6. 写真エリアを手動で指定したい場合だけ、JSONに `"photo": {"x":…,"y":…,"w":…,"h":…}` を書きます。

## ローカル確認
`node scripts/generate-manifest.mjs` のあと `python3 -m http.server` → http://localhost:8000

## 注意
無料のGitHub Pagesはリポジトリが公開になります。URLを知らない人には見つかりにくいだけで、機密情報は入れないでください。

## 補足
アプリはGitHub上の `stamps` / `templates` フォルダを直接読むため、Source が「Deploy from a branch」でも「GitHub Actions」でも、画像やJSONを追加・削除するだけで反映されます（公開反映に1〜3分、一覧のキャッシュ最大3分）。反映されないときは画面の「初期化」を押してください。`manifest.json` は読み込み失敗時の予備で、無くても動きます。

## 文字の装飾（テンプレートJSON）
text要素には任意で `"stroke": "#FEF4E8"`（縁取りの色）、`"strokeWidth": 10`（太さ）を追加できます。

## アプリアイコン
`icons/` の画像と `site.webmanifest` がホーム画面・インストール用のアイコン設定です。差し替える場合は同名のPNG（512×512 / 192×192 / 180×180 / 32×32）を上書きしてください。

## 背景画像を追加する
`backgrounds/カテゴリー名/画像ファイル` に置くだけです（フォルダ名は `background` でも可）（1080×1920の縦長がおすすめ。ほかの比率でもキャンバス全体を覆うように表示されます）。アプリの「写真・背景」タブから選べます。背景色は文字色と同じ6色から選べます。

## ロックと写真の調整
- 素材を選んで「ロック」を押すと、その素材は動かせなくなり、重なっている別の素材を触ってもつかまれません。ロック中の素材は、すばやく2回タップすると選べます（「ロック解除」で解除）。何も選んでいないときは「全ロック解除」になります。
- 「写真・背景」タブの「幅に合わせる」「高さに合わせる」で、写真を枠（フレーム型テンプレートでは写真が入る穴）の幅・高さにぴったり合わせます。
- 「左右中央」「上下中央」は写真にも使えます（写真は枠の中央にそろいます）。
- テンプレートJSONのスタンプ・文字に `"lock": true` を書くと、最初からロックされた状態で配置されます。

## 更新したのに表示が崩れるとき
スマホのブラウザが古い `app.js` / `style.css` を覚えていると、新しい画面と組み合わさって表示が崩れることがあります。`index.html` は読み込みファイルに `?v=…` の版番号を付けているため、`index.html` が更新されれば自動で新しいファイルを読み込みます。更新直後に崩れた場合は、10分ほど待つか、ブラウザの設定でサイトのデータ（キャッシュ）を削除してください。
